# CLAYDOX용 Excel 생성 (M5)

## 1. 방식

빈 Excel을 새로 만들지 않는다. KTL의 `계산식.xlsx`를 정리한 양식(`templates/clean_template.xlsx`)을 도구 안에 넣어두고, 시트 XML에서 **값 칸만** 바꾼 뒤 다시 묶는다. 그래서 서식·병합·열 너비·인쇄 설정·차트가 원본과 같다.

- 새 문자열은 `t="inlineStr"`(`<is><t>…</t></is>`)로, 숫자는 `<v>`로 넣는다. 기존 셀의 `s`(서식) 속성은 유지한다.
- 칸이 없으면 행·열 순서에 맞게 `<c>`를 끼워 넣는다. 바꾼 `<row>`의 `spans` 속성은 지운다.
- 서식과 차트를 버리는 라이브러리(SheetJS 무료판 등)로 다시 쓰지 않는다.

## 3. 채우는 칸

표기: `열행`. 행 n의 rep/lin/sen은 각 요약 CSV의 n번째 데이터 행.
CSV 열 기호는 `CALCULATION.md` 1절 표 기준 (B 기준유속, C 측정 유속, D 대기압, E 차압, F 압력, G 온도, H 습도, I 오차).

### 일반사항

| 셀 | 값 |
| --- | --- |
| D2 | 회사명 |
| D3 | 접수번호 |
| D5 | 주소 |
| D8 / G8 | 기기번호 / 모델명 |
| G10 / H10 | 최대유속 (숫자) / `(m/s)` |

| G3, D4, G4, D7, G9, G12, H12, G13 | 접수일자, 대표자, 전화번호, 직전·최초 정도검사일, 피토관 형식, 피토관 제작번호, 참조 성적서 번호 (입력했을 때만 덮어씀. 양식 기본값 `-`) |

### 구조확인

B1 = 접수번호. 사진 칸과 특이사항은 비워 둔다.

### 반복·직선성 raw data / sensitive raw data

- 1~13행: 반복성 요약 CSV / 민감도 요약 CSV의 1~13행을 A~K열에 그대로. 6~8행 B열(최대 유속, 피토관 직경, 정압 구멍 거리)은 숫자로.
- `반복·직선성 raw data` 14~23행 = 반복성 데이터, 24~33행 = 직선성 데이터 (머리글은 반복성 것만)
- `sensitive raw data` 14~43행 = 민감도 데이터
- 숫자로 읽히는 칸은 숫자로 넣는다.

## 4. 차트

`xl/charts/chart1.xml`(30 %), `chart2.xml`(70 %)은 아래를 참조한다.

- 제목: 계열 이름이 아니라 **차트 제목**(`<c:title>`)이다. 셀 `일반사항!$C$35:$C$36` / `$C$39:$C$40`(평균 유속)을 계열 이름으로 참조하는 것이 아니다. Excel이 읽은 계열 수식에는 이름 참조가 없다. 그래서 `<c:title>` 안 `<c:strCache>` idx 0을 평균 유속 소수 둘째 자리 문자열(`6.55 m/s`, `15.37 m/s`)로 바꾼다. 실제 Excel에서 제목이 맞게 나오는 것을 확인했다 (`planning/REALITY_CHECK.md`)
- X: `일반사항!$D$32:$H$32` (−10, −5, 0, 5, 10, 양식 상수) → 그대로
- Y: `(sensitive!$J$11,$J$17,$J$5,$J$23,$J$29)` / `($J$14,$J$20,$J$8,$J$26,$J$32)` → `<c:numCache>` pt 0~4를 각도 −10, −5, 0, +5, +10 순서의 그룹 값으로

Excel은 열 때 셀에서 차트를 다시 그리지만, CLAYDOX가 캐시를 읽을 수 있어서 캐시도 맞춰 둔다.

## 5. CLAYDOX 쪽 (참고)

CLAYDOX는 `sheetName` + `cellName`으로 값을 꺼낸다 (이해 자료 16쪽: `multi_text` 단일 값, `table` 범위, `chart2` 그래프). 그래서 **시트 이름과 셀 위치를 바꾸면 안 된다.** 매핑 설정은 시험 담당자가 한다. 이해 자료 예시는 시트 이름이 `일반`, `반복직선성_계산`인데 계산식.xlsx는 `일반사항`, `반복·직선성`이라 실제 이름 확인이 필요하다 (Q5). 셀 위치도 다르다. 이해 자료 예시는 형식승인번호를 일반 시트 `C9`로 적었지만, 계산식.xlsx 일반사항에서 `B9:C9`는 병합된 제목 칸(`형식승인번호`)이고 값은 `D9:E9`다. 이 문서는 `D9`를 기준으로 하며, CLAYDOX 명령이 `C9`를 쓰면 값 대신 제목을 읽으므로 시험 담당자가 매핑을 맞출 때 확인해야 한다.

## 6. 확인 방법

1. 자동: 만든 xlsx를 openpyxl 등으로 열어 `formula_cells.json`의 535칸이 모두 값이 있는지, 병합 58개(일반사항)·차트 2개가 그대로인지 확인
2. 자동: 압축을 풀어 `[1]`, `externalLink`, `calcChain`, `ctrlProp` 문자열이 없는지 확인
3. 사람: Microsoft Excel에서 열어 복구 경고가 없는지, 그래프에 점이 찍히는지 확인
