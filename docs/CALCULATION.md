## 2. 내용으로 종류 판별

파일 이름은 쓰지 않는다 (실제 파일명에 `source.csvurce.csv` 같은 오타가 있음).

1. 요약/source: 12행 첫 칸이 `저장번호`면 요약, `시험번호`면 source. 둘 다 아니면 판별 불가.
2. 측정점 만들기: 첫 열(번호) 값으로 묶고 각 묶음의 기준유속 평균을 낸다. 요약은 B열, source는 D열. 요약은 한 행이 한 점이다.
3. 시험 종류 (측정점 수 n, 측정점 값 p[0..n-1]):
   - n = 30 → 설치방향 민감도
   - n = 10이고 p가 낮음·높음을 번갈아 감 (p[i] < p[i+1] 이 i가 짝수일 때 참, 홀수일 때 거짓) → 반복성
   - n = 10이고 max(p[0..4]) < min(p[5..9]) → 직선성
   - 그 밖 → 판별 불가
4. 짝 확인: 같은 시험의 요약과 source는 11행 교정 시간이 같다 (견본: 반복성 13:37:27, 직선성 13:30:24, 민감도 11:14:15).

절대 유속값(2 m/s 등)을 쓰지 않으므로 최대 유속이 다른 장비에서도 그대로 통한다. 6개를 섞어 넣고 파일 이름을 f1~f6.csv로 바꿔도 맞게 판별되는 것을 확인했다.

## 4. 계산

최대유속 R = 1~11행 머리글 6행 B열 (견본 22).

### 4.1 반복성

반복성 요약 10행: **홀수 행(1,3,5,7,9) = ZERO (약 2 m/s), 짝수 행 = SPAN (약 17.7 m/s)**.

```
ZERO(%) = 표본표준편차(ZERO 5행의 측정 유속) / R × 100
SPAN(%) = 표본표준편차(SPAN 5행의 측정 유속) / R × 100
반복성 = max(ZERO, SPAN)
```

표본표준편차는 n-1로 나눈다 (Excel `STDEV`). 원본 수식: `일반사항!E21 = STDEV(E16:F20)/$G$10*100`.

### 4.2 직선성

직선성 요약 10행: **1~5행 = 측정범위 30 % 지점 (약 6.6 m/s), 6~10행 = 70 % 지점 (약 15.4 m/s)**.

```
행별 오차(%) = |기준유속 − 측정 유속| / 기준유속 × 100
30 % = max(1~5행 오차), 70 % = max(6~10행 오차)
직선성 = max(30 %, 70 %)
```

원본 수식: `일반사항!E30 = MAX(ABS(E25-F25)/E25*100, …)`.

같은 파일의 `반복·직선성!J20`에는 평균 방식 `(평균 측정 − 평균 기준)/평균 기준 × 100`도 있다. 어느 쪽이 성적서 기준인지 미정이다 (Q1). 지금은 MAX 방식으로 판정하고, 평균 방식 값은 Excel의 J20·J25에만 넣는다.

### 4.3 설치방향 민감도

민감도 요약 30행의 `오차` 열(I열, 풍동 프로그램이 계산한 값)을 3행씩 묶는다. I열은 (측정−기준)/기준×100과 6개 요약 파일 전체에서 최대 4.6e-8 %p(CSV 자릿수 반올림)까지만 다르다. 그래서 다시 계산하지 않고 I열 값을 그대로 쓴다 (설정 `sensitivityErrorSource` = `column`). 각도는 CSV에 없고 **행 순서로만 정해진다** (Q3).

| 행 | 각도 | 지점 | | 행 | 각도 | 지점 |
| --- | --- | --- | --- | --- | --- | --- |
| 1~3 | 0° | 30 % | | 16~18 | −5° | 70 % |
| 4~6 | 0° | 70 % | | 19~21 | +5° | 30 % |
| 7~9 | −10° | 30 % | | 22~24 | +5° | 70 % |
| 10~12 | −10° | 70 % | | 25~27 | +10° | 30 % |
| 13~15 | −5° | 30 % | | 28~30 | +10° | 70 % |

```
그룹 값(%) = |3행 오차의 평균|
민감도 = max(10개 그룹 값)
30 % 평균 유속 = 30 % 그룹 15행 기준유속 평균 (그래프 제목용, 일반사항!C35)
70 % 평균 유속 = 70 % 그룹 15행 기준유속 평균 (일반사항!C39)
```

원본 수식: `sensitive!J5 = ABS(AVERAGE(I5:I7))`, `sensitive!J36 = MAX(J5:J34)`.

### 4.4 시험 환경 조건

반복성·직선성·민감도 요약 50행 전체에 대해:

- 대기압(hPa) = 대기압(kPa) × 10 의 최소·최대·중간값. 배수 10은 고정이며 CSV 13행의 단위 칸은 읽지 않는다 (설정 `pressureKpaToHpa`). 원본 수식은 단위 칸(kPa·atm·bar·psi·torr·Pa)에 따라 배수가 바뀌지만, 풍동 프로그램 CSV는 kPa다.
- 온도(℃), 상대습도(%) 의 최소·최대·중간값
- 중간값 = (최소 + 최대) / 2

원본 수식: `반복·직선성!C30:G32`.

### 4.5 장비 정보

- 접수번호 = 1행 B열에서 첫 공백 앞 (`25-123456-01-1`), 회사명 = 첫 공백 뒤. 원본 수식 `LEFT(…,15)`는 14글자 접수번호에서 뒤에 공백 1칸이 붙지만, 이 도구는 공백 없이 쓴다 (설정 `receiptNoMode` = `firstToken`)
- 검사일자 = 10행 숫자 세 개를 `YYYY년 MM월 DD일`로 (`2025년 10월 20일`)
- 주소, 기기 종류, 모델명, 기기번호, 최대유속은 머리글 그대로
- 속도 단위 표기(일반사항 H10)는 `(m/s)` 고정이다 (설정 `velocityUnitLabel`). 원본 수식은 기기 종류가 피토관이 아니면 `(Sm/s)`를 쓰지만, 이 도구의 대상은 피토관이다.

## 5. 판정과 표시

| 항목 | 기준 | 판정 |
| --- | --- | --- |
| 반복성 | 2.0 % 이하 | 값 ≤ 2.0 이면 적합 |
| 직선성 | 5.0 % 이하 | 값 ≤ 5.0 이면 적합 |
| 설치방향 민감도 | 4.0 % 이하 | 값 ≤ 4.0 이면 적합 |
| 현장적용계수 | — | 「해당없음」 고정 |
| 종합 | — | 세 항목 모두 적합이면 적합 (Excel에는 `적 합` / `부적합`, 원본 표기) |

- 판정은 **반올림 전 값**으로 한다 (Q2 답이 오면 바뀔 수 있음).
- 비교 직전에 계산값을 유효숫자 15자리로 정리해 부동소수 잡음만 걷는다 (사람 승인, 설정 `judgeSignificantDigits` = 15). 값을 소수 첫째 자리로 반올림하는 것이 아니다. 예: 직선성 기준 1.000, 측정 1.050이면 계산값은 5.000000000000004이고 15자리로 정리하면 5.00000000000000이 되어 5.0 이하이므로 표시 5.0, 판정 적합이다. 5.0000001은 정리해도 그대로라 부적합이다.
- 화면 표시값은 소수 첫째 자리 **사사오입** (0.05 → 0.1, 2.05 → 2.1). 계산값은 소수 넷째 자리까지 함께 보여준다.
- Excel에는 반올림하지 않은 값을 넣는다. 보이는 자릿수는 양식의 셀 서식이 정한다.
