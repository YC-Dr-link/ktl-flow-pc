# M4·M5 프로토타입 기반 작업 인계

기준: 제공된 `m4m5.html` v0.2.1-proto와 공동 문서 01~06. 원본·견본은 저장소 밖에서 읽기만 했다. 공동 계약은 변경하지 않는다.

## 이번 이슈 #1에서 가져온 것

- 원본 CSS의 색상·간격·카드·파일 패널·고정 저장 버튼·반응형 스타일.
- 한 화면에서 파일을 넣고 결과를 확인하는 작업대. 좁은 화면에서 결과 → 파일 패널로 DOM을 배치해 Tab 순서도 맞춘다.
- 파일 6칸과 판별 근거 펼치기, 결과 카드, 일반사항·출력 미리보기의 연결 자리.
- 선택·끌어놓기·교체·초기화는 파일 메타데이터만 표시한다. 파일명으로 종류를 배정하지 않는다.

## 포함하지 않은 것

- HTML에 내장된 견본 CSV 6개, 견본 실행 버튼, Excel 양식 바이너리와 별도 견본 파일.
- 원본의 압축된 JSZip·pako·xmldom 및 판별·계산·Excel 번들. 원본 계산 결과를 검산 없이 완료 처리하지 않는다.
- 원본의 자동 판정·바로 저장 동작. 시험자 확인 전 내보내기를 허용하지 않는 공동 원칙을 후속 이슈에서 적용한다.

## 후속 이슈의 연결 위치

| 작업 | 시작 위치 | 확인할 계약 |
|---|---|---|
| QR 검증·한글 입력 복원 | `src/app.js`, `#qr-input` | 02 §4, QR 벡터, REQ-A2-01~02 |
| 합성 풍동 CSV 생성 | `synthetic/` (해당 이슈에서 추가) | 실제 견본을 복제하지 않고 가짜 값·정답 생성 |
| CSV 읽기·내용 판별·수동 배정 | `selectFiles`, `state.files`, `#slots` | cp949·12행 칼럼·13행 단위, REQ-A2-03·07 |
| 반복성·직선성·민감도 | `#results` 결과 카드 | 02 §5 수식, REQ-A2-04·09, 합성 정답 소수 셋째 자리 |
| 통일 Excel·출처·그래프 | `#saveBtn`, 일반사항·셀 미리보기 | REQ-A2-05·06·08, 원본 SHA-256 및 시험자 확인 |

기능이 커지면 `src/` 내에서 모듈을 나누고 빌더가 최종 HTML에 포함하도록 확장한다. CDN·런타임 파일 불러오기는 추가하지 않는다. 원본 번들 전체를 복사하는 대신 필요한 로직을 읽을 수 있는 소스로 옮기고 합성 정답으로 검증한다.

## 공동 계약과 차이 — 사용자 확인 완료

2026-11-02 사용자가 “현재는 프로토타입이고 공동계약에 맞게 작업하는게 맞아”라고 확인했다. 프로토타입 출력 양식을 새 기준으로 삼지 않는다.

- 프로토타입 Excel은 `sensitive`와 반복직선성·민감도별 raw data 시트가 있다. 공동 계약의 `민감도`, `raw data`, `출처` 등 정해진 시트·셀 위치로 후속 이식한다.
- 원본의 회사명 포함 CLAYDOX 파일명 대신 공동 문서 02 §5의 출력 파일명 규칙을 따른다.
- 원본의 화면 자동 계산·저장 가능 상태를 시험자 확인 완료와 혼동하지 않는다.
- QR·원본 해시·출처 추적은 화면 모양을 재사용하는 것과 별도로 구현·검증한다.
