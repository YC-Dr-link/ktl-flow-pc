# CLAYDOX용 Excel 생성 (M5)

## 1. 방식

빈 Excel을 새로 만들지 않는다. 사용자가 실행할 때 PC에 있는 계산식 양식 파일(.xlsx)을 고르면, 그 양식의 시트 XML에서 **값 칸만** 바꾼 뒤 다시 묶는다. 양식 파일은 도구(HTML)와 레포에 넣지 않는다 (ktl-hub 협업 규칙 1.1, 계약 02 §5). 한 번 고른 양식은 그 PC의 브라우저 저장소에 기억한다. 테스트·시연에는 직접 만든 합성 양식 `synthetic/template_synthetic.xlsx`(시트 이름 6개와 차트 2개만 있고 서식은 없다)를 쓴다. 그래서 서식·병합·열 너비·인쇄 설정·차트가 원본과 같다.

- 새 문자열은 `t="inlineStr"`(`<is><t>…</t></is>`)로, 숫자는 `<v>`로 넣는다. 기존 셀의 `s`(서식) 속성은 유지한다.
- 칸이 없으면 행·열 순서에 맞게 `<c>`를 끼워 넣는다. 바꾼 `<row>`의 `spans` 속성은 지운다.
- 서식과 차트를 버리는 라이브러리(SheetJS 무료판 등)로 다시 쓰지 않는다.

### 작년 Excel에서 불러오기 · 일반사항 유지 (#24)

- 저장 화면 「작년 Excel에서 불러오기」로 같은 기기의 작년 파일(이 도구가 만든 파일 또는 같은 양식의 xlsx · xlsm)을 고르면, 일반사항 시트에서 아래 칸을 읽어 **비어 있는 입력 칸만** 채운다 (`src/excel/readPrevious.js`). 기기 번호(D8)가 지금 기기와 다르면 채우지 않는다.
  - D4 대표자, G4 전화번호, G7 제작회사, D9 형식승인번호, D10 형식승인일자, G9 최초 정도검사일, G12 피토관 형식, H12 피토관 제작번호, H11 피토계수, G6 호기(`ST 2` → `2`)
  - 작년 D11(시험일자) → 올해 직전 정도검사일(D7)
  - 접수일자(G3)와 참조 성적서 번호(G13)는 올해 값이라 불러오지 않는다. 「-」는 빈칸으로 본다.
- 새 CSV를 넣을 때 같은 기기(기기 번호 같음)면 사람이 넣은 일반사항을 남기고, 다른 기기면 비우고 알린다.
- 날짜 칸(접수일자 · 직전/최초 정도검사일 · 형식승인일자)이 `YYYY년 MM월 DD일` · `YYYY.MM.DD`가 아니면 노란 안내를 띄운다. 저장은 막지 않는다.
- 피토계수는 `0,826`처럼 쉼표 소수점도 숫자로 저장한다.

### 접수번호 · 회사명과 파일 이름 (#23)

- CSV 1행 「의뢰 기관」을 `NN-NNNNNN-NN(-N|-NN)` 꼴의 접수번호와 회사명으로 나눠 저장 화면 「접수번호 · 회사명 확인 (필수)」 칸에 미리 넣는다 (`src/core/receipt.js`).
- 공백 없이 붙었거나(`25-000123-01-1업체A`) 꼴이 아니면 크게 경고하고, 사람이 확인 체크를 해야 저장된다. 접수번호 꼴이 틀리면 저장하지 않는다.
- 확인한 값이 일반사항 D2 · D3, 반복·직선성 · sensitive · 구조확인 시트의 B1, 파일 이름에 들어간다.
- 저장 파일 이름은 `<접수번호-세부>_유속계.xlsx`다 (`config.fileNamePattern`, hub #16 PM 제안). 회사명은 파일 안에만 둔다.

## 4. 차트

`xl/charts/chart1.xml`(30 %), `chart2.xml`(70 %)은 아래를 참조한다.

- 제목은 `sensitive!$AC$1` / `$AD$1`을 참조하는 **차트 제목**(`<c:title>`)입니다. 해당 셀에 평균 유속 소수 둘째 자리와 ` m/s`를 쓰고 `<c:strCache>`도 갱신하여 재계산 후에도 제목을 유지합니다. 실제 연구원 양식의 호환 확인은 별도로 필요합니다.
- X: `일반사항!$D$32:$H$32` (−10, −5, 0, 5, 10, 양식 상수) → 그대로
- Y: `(sensitive!$J$11,$J$17,$J$5,$J$23,$J$29)` / `($J$14,$J$20,$J$8,$J$26,$J$32)` → `<c:numCache>` pt 0~4를 각도 −10, −5, 0, +5, +10 순서의 그룹 값으로

Excel은 열 때 셀에서 차트를 다시 그리지만, CLAYDOX가 캐시를 읽을 수 있어서 캐시도 맞춰 둔다.

## 5. CLAYDOX 쪽 (참고)

CLAYDOX는 `sheetName` + `cellName`으로 값을 꺼낸다 (이해 자료 16쪽: `multi_text` 단일 값, `table` 범위, `chart2` 그래프). 그래서 **시트 이름과 셀 위치를 바꾸면 안 된다.** 매핑 설정은 시험 담당자가 한다. 이해 자료 예시는 시트 이름이 `일반`, `반복직선성_계산`인데 계산식.xlsx는 `일반사항`, `반복·직선성`이라 실제 이름 확인이 필요하다 (Q5). 셀 위치도 다르다. 이해 자료 예시는 형식승인번호를 일반 시트 `C9`로 적었지만, 계산식.xlsx 일반사항에서 `B9:C9`는 병합된 제목 칸(`형식승인번호`)이고 값은 `D9:E9`다. 이 문서는 `D9`를 기준으로 하며, CLAYDOX 명령이 `C9`를 쓰면 값 대신 제목을 읽으므로 시험 담당자가 매핑을 맞출 때 확인해야 한다.

## 7. 출처 기록과 최종값 (#7)

저장 화면에서 만든 결과에는 기존 양식 뒤에 `출처` 시트를 추가합니다. 원본 파일 6개의 전체 바이트 SHA-256, 파일명, 시험/결과·source 종류, 자동·수동 배정, 원본/데이터 행 수, 인코딩, 도구 버전, 생성·확인 시각, 확인 접수번호·회사명과 CSV 원문 값, 판별 근거와 raw 위치를 기록합니다. 확인은 저장 동작을 시작한 시점이며 시험자 신원 인증을 뜻하지 않습니다.

원본의 나머지 블록은 `반복·직선성 raw data`의 M열(반복성 source), X열(직선성 결과 원본), AJ열(직선성 source)과 `sensitive raw data` M열(source)에 기록합니다. 블록의 1행은 CSV의 1행이며 source 문자열은 문자열 셀로 저장합니다. 기존 A~K 요약 배치를 함께 제공합니다.

PM의 #7 지시에 따라 일반사항 I21에 반복성 최종값, I30에 직선성 최종값을 숫자로 기록합니다. **TODO(확인 필요): 실제 양식·CLAYDOX에서 읽을 최종 위치(Q14)**. 차트 제목은 sensitive AC1·AD1을 참조하고 평균 유속 뒤에 ` m/s`를 붙입니다.

개발용 기존 `buildXlsx` 호출은 그대로 사용할 수 있습니다. 여섯 번째 인수에 `{files, analysis, confirmedAt}`를 전달하면 원본 6개를 다시 검증하여 출처와 추가 raw 블록을 기록합니다. 제품의 저장 버튼은 항상 이 인수를 전달합니다.

수동 선택은 추가 후보·판별 불가 파일을 포함하여 최대 30개, 파일당 25 MB, 합계 100 MB까지 허용합니다. 6칸을 직접 배정한 경우에도 선택한 전체 목록을 재검증하고 실제 사용한 6개만 출처와 raw 블록에 기록합니다. 읽기 실패·용량 초과는 현재 결과·입력값을 지우지 않고 안내합니다.

## 8. 양식 안전성 검사

출력에 사용할 양식은 외부 관계·외부 연결 수식·VBA/Excel 4 매크로·ActiveX·OLE를 포함하면 사용을 거부합니다. 자동 실행 이름 정의와 외부 연결을 실행할 수 있는 이름 정의 수식도 검사합니다. 원본 양식의 연결을 자동 삭제하지 않습니다. 압축 파일 25 MB, 해제 후 100 MB, XML 부품 10 MB, 항목 2,000개를 상한으로 검사하며, 크기 표기를 속인 XML은 실제 해제 중에도 제한합니다. 실제 양식이 거부되면 PM과 안전한 별도 양식의 준비 방법을 확인해야 합니다.

작년 xlsm은 일반사항 값만 읽으며 활성 부품을 결과로 복사하거나 실행하지 않습니다. 같은 압축 용량 제한을 적용합니다. 저장 화면의 `기억한 양식 지우기`로 이 브라우저에 저장한 양식과 현재 선택을 지울 수 있습니다.

CSV·양식·작년 Excel을 연속으로 고르면 마지막 선택의 읽기 결과와 오류만 반영합니다. 양식을 지우면 진행 중인 선택·복원도 무효화하여 뒤늦게 다시 저장되지 않습니다. CSV를 다시 선택하거나 칸 배정을 바꾸면 진행 중인 작년 Excel 읽기를 취소합니다. 파일 확인 중에는 저장을 기다리도록 안내하며, Excel을 저장하는 동안 새 선택은 반영하지 않고 일반사항·접수번호 입력과 뒤로 가기를 잠급니다. 저장이 끝나거나 실패·취소되면 입력을 다시 열어 줍니다.

저장 창 복귀 후뿐 아니라 파일 쓰기 준비 완료 후와 쓰기 후 확정 직전에도 현재 결과인지 확인합니다. 그사이 재측정이 확인되면 임시 쓰기를 중단합니다. 날짜 숫자는 1900·1904 체계별 9999년 12월 31일 상한을 적용합니다. 계산 중 무한대·NaN이 생기면 결과와 판정을 확정하지 않고 오류로 안내합니다.

폴더 감시 중 장비가 CSV를 쓰고 있어 파일을 일시적으로 읽지 못하면 저장을 보류하고 재시도합니다. 정상 재조회에서 현재 기기와 무관한 파일로 확인되면 보류를 해제합니다. 권한 오류로 감시를 중지한 경우에는 중지 안내를 표시합니다.

폴더를 선택하기 전에 있던 CSV도 새 CSV와 함께 안정화·검증하여 한 기기분씩 반영 후보로 보여 줍니다. 기존 화면을 자동으로 덮어쓰지 않으며 최초 반영은 사용자가 누릅니다. 수동 파일 선택·칸 재배정 뒤에는 이전 폴더 반영 안내와 저장 완료 표식을 재사용하지 않습니다.

저장하지 않은 결과를 직접 고른 CSV로 교체할 때는 확인 창을 띄웁니다. 취소하면 결과·일반사항·접수 확인 내용을 유지합니다. 성공적으로 저장한 파일·분석·입력값이 그대로라면 다시 묻지 않으며, 저장 후 일반사항이나 접수번호를 고쳤으면 다시 확인합니다. 날짜는 안내만 하고 저장을 막지 않는 기존 정책을 유지합니다.

통합 문서와 관계 XML에 접두사(`x:sheets`, `p:Relationship` 등)가 있어도 출처 시트를 추가·재사용할 수 있습니다. 실제 연구원 양식의 전체 호환 검증을 대신하는 것은 아닙니다.
