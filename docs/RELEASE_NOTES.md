## 무엇이 되는가

- `dist/m4m5.html` 한 파일을 더블클릭(`file://`)으로 열어 쓴다. 네트워크가 필요 없고 외부 URL 참조가 0건이다.
- 유속계 정도검사 rawdata CSV 6개(반복성 요약, 반복성 데이터, 직선성 요약, 직선성 데이터, 민감도 요약, 민감도 데이터)를 넣으면 파일 내용으로 종류를 판별해 배정한다. 파일 이름 순서는 상관없다.
- M4: 반복성, 직선성, 민감도 계산과 판정(기준 2.0 / 5.0 / 4.0 %)을 결과 화면에 보인다. 부적합은 표시값·계산값·판정을 함께 보인다. 오류와 경고는 한국어로 보인다.
- M5: 정리된 양식(`templates/clean_template.xlsx`)에 값을 채워 CLAYDOX용 Excel을 내려받는다. 파일 이름은 `<접수번호> <회사> CLAYDOX.xlsx` 형식이다.
- `dist/sample.xlsx`: 견본 25-123456-01-1로 만든 결과 Excel 예시 (`npm run sample`로 생성).

## v1(0.1.0-proto)에서 바뀐 것 (사용자 눈에 보이는 변경)

- 3단계 화면(파일 넣기 → 결과 확인 → Excel 저장)을 **한 화면**으로 합쳤다. 「넣은 파일」 6칸과 결과가 한 화면에 있고(넓은 화면에서는 나란히, 좁은 화면에서는 세로로), 맨 위 줄에 저장 버튼이 있다. 단계 탭과 자동 이동이 없다 (FR-M4-11).
- 6칸이 채워지면 같은 화면에 결과가 바로 나온다. 결과 맨 위가 종합판정이고, 카드 3개가 가로로 놓이며, 1366×768 첫 화면 안에 들어온다. v1의 「종합판정이 첫 화면 아래」는 해소됐다.
- 칸마다 칸 이름·파일 이름·「자동」 또는 「직접 고름」이 보인다. 칸을 누르면 판별 근거가 보이고 다른 파일로 바꾸면 이동 없이 다시 계산한다.
- 오류가 있으면 결과 없이 오류(파일·행·이유)만 보이고 6칸은 그대로다. 판별 불가 파일은 결과를 가리지 않는 「알림 N건」으로 보인다.
- (V2 동작, V3에서 대체됨) 저장 버튼 고정과 접힌 선택 입력은 V3의 저장 화면으로 바뀌었다. 아래 V3 항목을 본다.
- 결과가 나오면 화면 낭독기에 「N개 파일을 칸에 배정하고 검증을 통과해 결과를 표시했습니다.」를 알린다. 오류일 때는 오류 건수를 알린다.
- **V3 (이번 변경)**: 결과 화면의 장비 정보를 「장비」·「접수」 두 묶음으로 나눴다. 「설치 방향 및 민감도 그래프, 시험 환경 조건」·「CLAYDOX가 읽는 주요 셀」·「계산에 쓴 행」은 장비 정보 아래 버튼 3개로 열리는 모달(창) 3개로 옮겼다(Esc·닫기로 닫고, 열면 초점이 창 제목으로 가며, 열려 있는 동안 배경 스크롤이 잠긴다). 「Excel 만들고 저장」은 바로 내려받지 않고 「Excel로 저장」 화면으로 넘어가며, 일반사항 13칸(모두 선택)을 채워 「Excel 저장」으로 내려받는다. 「뒤로」로 결과 화면에 돌아올 수 있고 입력값은 새 CSV를 넣기 전까지 유지된다. 판정 카드는 적합 초록, 부적합 빨강이다. 계산·Excel 출력은 그대로다 (`src/core`·`src/excel`·`templates` 변경 0).
- UIPRO 보완(UI/UX Pro Max): 좁은 화면에서 Tab·낭독 순서를 화면 순서(결과 먼저)와 맞췄고, 민감도 그래프 글자를 실제 14px로 키웠고, 입력 칸 글자 16px·배지 13px, touch-action·전화번호 inputmode, 색 토큰을 정리했다. 계산·Excel 출력은 그대로다.
- v1 루프에서 넣은 것(초점 링·입력 테두리 대비, 「표시값」 라벨, 눌림 표시 등)은 유지된다.
- 계산식·행 매핑·판정 기준·Excel 출력은 v1과 같다 (`src/core`, `src/excel`, `templates`, `scripts` 변경 0, 출력 xlsx 내용 차이 0).
